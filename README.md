# Simple AI Model Adversarial Attack

This example demonstrates a basic concept of AI model security by showing how a simple text classifier can be manipulated through an 'adversarial attack'. It illustrates how small, targeted changes (like typos or 'leetspeak') to input data can cause a model to make incorrect predictions, highlighting a fundamental vulnerability in AI systems.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
